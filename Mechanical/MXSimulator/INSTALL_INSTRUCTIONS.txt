MXSimulator - Cap Vibration Time Force Setup
설치 및 실행 가이드
=================================================================

ANSYS Student 버전에서는 ACT Extension이 제한될 수 있습니다.
아래 "Direct Scripting 방식"을 사용하세요.

-----------------------------------------------------------------
방법 1: Direct Scripting (권장 - 모든 버전에서 작동)
-----------------------------------------------------------------

1. ANSYS Mechanical 실행

2. View → Scripting (또는 Ctrl+E)

3. Open 버튼 클릭

4. 다음 파일 선택:
   C:\Users\<사용자명>\AppData\Roaming\ANSYS\v252\ACT\extensions\MXSimulator\run_cap_vibration.py

5. Run Script 버튼 (F5)

6. Cap Vibration 대화창이 열립니다!


** 빠른 실행을 위한 팁 **

Scripting 창에서 Favorites → Add로 스크립트를 즐겨찾기에 추가하면
다음부터는 즐겨찾기에서 바로 실행 가능합니다.

-----------------------------------------------------------------
방법 2: ACT Extension (Commercial 버전 전용)
-----------------------------------------------------------------

Commercial 라이센스 버전에서만 작동할 수 있습니다.

1. Workbench 완전 종료

2. Workbench 재시작 → Mechanical 열기

3. 리본에서 "MXSimulator" 탭 찾기

4. Load 그룹 → "Cap Vibration" 버튼

** 주의: Student 버전에서는 작동하지 않을 수 있습니다 **

-----------------------------------------------------------------
Phase 1 기능
-----------------------------------------------------------------

✅ STEP 파일 임포트
✅ 면 법선 방향 자동 분석 (±X, ±Y, ±Z)
✅ 방향별 Named Selection 자동 생성
✅ 실시간 로그 출력

사용법:
1. Browse로 STEP 파일 선택
2. "Import and Analyze Faces" 클릭
3. "Create Named Selections" 클릭
4. Model Tree에서 Contact_+Z, Contact_-Z 등 확인

-----------------------------------------------------------------
문제 해결
-----------------------------------------------------------------

Q: run_cap_vibration.py 파일이 없습니다
A: MSI 인스톨러를 다시 실행하거나, 프로젝트를 빌드하세요.

Q: 스크립트 실행 시 오류 발생
A: 오류 메시지를 복사하여 개발자에게 전달하세요.

Q: ACT Extension 탭이 안 보입니다
A: Student 버전에서는 제한됩니다. 방법 1 (Direct Scripting)을 사용하세요.
